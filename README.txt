PERSONAL JOB APPLICATION BOT — STARTER VERSION
===============================================

What this version does
- Runs locally on your Windows PC in your browser.
- Lets you upload a resume and save a basic applicant profile.
- Provides job-search links for entry-level, gaming/QA, and general jobs.
- Lets you save job listings and track application status.
- Uses a 1-mile local search radius for on-site/hybrid search links, with Miami Lakes, FL as the starting location.
- Lets you search remote roles too.

Important limitation
This is a starter application, not a universal automatic submitter yet. Job sites use different forms, logins, terms, and anti-bot protections. There is no reliable universal way to submit every application automatically. This version does not bypass CAPTCHA or site restrictions and does not submit forms silently. To add genuine automated submission, integrations must be built and tested for specific permitted employer platforms, using your approved profile and stopping for verification or sensitive questions.

How to run
1. Install Python 3.11 or newer from https://www.python.org/downloads/
   During setup, enable "Add Python to PATH".
2. Extract this ZIP to a folder you can find.
3. Double-click run_windows.bat.
4. A browser tab should open with the dashboard.
5. Upload your resume in the Resume tab.

Files and privacy
- Resume files are stored in the app's uploads folder.
- Profile details are stored in profile.json.
- Application tracking is stored in applications.db.
- Keep this folder private. Do not share it publicly.
- Do not store passwords, Social Security numbers, bank details, or identity documents in this starter app.

Suggested target profile
- Gaming/game development plus other jobs you qualify for
- High school diploma
- Entry-level / no experience required
- On-site or hybrid within 1 mile of Miami Lakes, FL
- Remote jobs may be searched nationwide
- No fixed daily application cap; prioritize suitable, non-duplicate openings
